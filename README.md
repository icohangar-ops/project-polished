## Why the move?

The Solari Cookbook bounty explicitly requires submissions to be a fork of
`solari-sdk/solari-cookbook`. This standalone repo was the initial draft;
Project Polished has now been added as a proper example inside the cookbook
fork, where it sits alongside the other official examples
(`browser-quickstart-ts`, `desktop-computer-use-py`, etc.).
